# 📌 Overview

AegisIQ is an AI-powered Industrial Asset Monitoring and Predictive Maintenance Platform designed to help organizations monitor critical industrial assets, analyze infrastructure health, detect failures before they occur, and optimize maintenance operations using AI-driven insights.

Unlike traditional monitoring systems that simply display dashboards and alerts, AegisIQ combines infrastructure intelligence, AI-powered decision support, and predictive maintenance into a single platform.

---

# 🎯 Problem Statement

Modern industrial organizations face several operational challenges:

* Unexpected equipment failures
* High maintenance costs
* Lack of real-time infrastructure visibility
* Manual incident investigation
* Delayed root cause analysis
* Unplanned operational downtime
* Inefficient maintenance scheduling

These issues reduce productivity, increase operational costs, and impact business continuity.

---

# 💡 Solution

AegisIQ provides an intelligent infrastructure monitoring platform that enables organizations to:

* Monitor industrial assets in real time
* Track asset health continuously
* Detect infrastructure anomalies
* Generate intelligent alerts
* Manage maintenance schedules
* Analyze infrastructure dependencies
* Recommend AI-powered corrective actions
* Improve operational efficiency

---

# 🚀 Innovation

Unlike conventional monitoring tools, AegisIQ acts as an **AI Decision Support Platform**.

Instead of only notifying administrators after failures occur, AegisIQ helps prevent failures by analyzing infrastructure behavior, understanding system dependencies, learning from previous incidents, and recommending the best possible actions.

This transforms infrastructure management from:

**Reactive Maintenance ➜ Proactive Monitoring ➜ Predictive Maintenance**

# 🔄 Reactive vs Proactive vs Predictive

## Reactive

* Failure occurs
* Alert generated
* Engineer investigates
* Downtime already happened

## Proactive

* Health continuously monitored
* Early warnings generated
* AI recommends preventive actions
* Downtime minimized

## Predictive

* AI predicts future failures
* Maintenance scheduled before breakdown
* Improved asset reliability
* Reduced operational cost

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Sabariswaran-java/AegisIQ.git
```

---

## Backend

1. Import the backend project into Spring Tool Suite or IntelliJ IDEA.
2. Configure the PostgreSQL database.
3. Run the Spring Boot application.

---

## Database

1. Open PostgreSQL.
2. Create a database named:

```text
aegisiq
```

3. Open pgAdmin.
4. Execute:

```text
database/schema.sql
```

---

## Frontend

Open:

```text
frontend/index.html
```

or use **Live Server**.
